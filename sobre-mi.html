Sobre Mí

Hola, soy Kevin. Estudio Tecnología en Desarrollo de Software e Ingeniería de Software y Datos. Me gusta construir aplicaciones completas, desde la base de datos hasta la pantalla, y aprender la herramienta que haga falta para que funcionen.

Mi base es Java y Spring Boot, pero también he trabajado con Angular, React, MySQL, MongoDB y Python básico. Mi proyecto más completo es Ahorrix, una aplicación que vigila precios en tiendas colombianas y avisa por correo cuando bajan. También hice un chat en tiempo real y un servicio de exámenes con pruebas unitarias.

Busco una práctica profesional desde inicios de 2027 en un equipo de desarrollo. Quiero aprender de ingenieros con experiencia, trabajar con las tecnologías que use el equipo y aportar con lo que ya sé hacer. Mientras tanto, sigo aprendiendo con proyectos propios.

Lo que hago

Desarrollo backend

Hago APIs REST con Java y Spring Boot y las conecto a bases de datos como MySQL o MongoDB. Pruebo la lógica con JUnit y Mockito.

Integraciones y tareas automáticas

Uso WebSockets para chats en tiempo real, Jsoup para leer precios de tiendas y tareas programadas que envían alertas por correo.

Buenas prácticas

Separo el código en capas, uso Git y GitHub y escribo pruebas unitarias para que cada parte sea fácil de entender y de cambiar.

Frontend y más

Hago interfaces sencillas en Angular y React y tengo bases de Python. Estoy listo para aprender lo que pida el proyecto.
